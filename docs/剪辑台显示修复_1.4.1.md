# 剧情剪辑台「在酒馆里显示不对」的定位与修复（v1.4.1）

> 现象（用户反馈）：百宝月夜书的「剧情剪辑台」在 SillyTavern 里打开后显示有问题 —— 看不出来是个面板，内容挤在页面末尾 / 被聊天区盖住 / 背景透明看不清。
> 结论：**不是数据问题，是面板容器完全没有样式**，并且容器拿不到主题变量。本版把容器做成一个正经的右侧抽屉。

---

## 一、剪辑台是怎么挂上去的（现状）

```
document.body
└── #bbs-app-host                ← 留在 ST 的 light DOM，inline !important 切断继承，display:contents
    └── #shadow-root (open)      ← 注入 dist/index.css 的 <link>
        ├── <div>                ← Vue 应用挂载点
        │   └── .bbs-root        ← 主题令牌 --bbs-* 定义在这里（theme.css）
        │       └── … 柏宝书窗口、楼层摘要面板 …
        └── #bme-panel-host      ← 【剪辑台面板容器】1.4.0 新增，与 .bbs-root 是兄弟节点
            └── .bme-root + <style>＋页签＋正文   ← createPanel() 直接挂在这里
```

挂载链路（v1.4.0）：

- `src/index.ts → mount()`：建 `#bme-panel-host` → `editorHost.hidden = true` → `mountMemoryEditorPanel(editorHost)`；
- `src/index.ts → bindMemoryWhenReady()` → `bindMemoryEditor()`（`src/features/memory-editor/host.ts`）：`createMemoryEditor(...)` → `editor.attach(panelContainer)`；
- 入口：魔杖菜单「剧情剪辑台」→ `toggleMemoryEditorPanel()` 翻转 `panelContainer.hidden`。

## 二、为什么会显示不对（两个根因，都是硬伤）

### 根因一：`#bme-panel-host` 没有拿到主题令牌

主题变量全部定义在 `.bbs-root` 上（`src/styles/theme.css`）：

```css
.bbs-root { --bbs-font-sans: …; --bbs-radius: …; }
.bbs-root[data-theme='day']   { --bbs-bg: …; --bbs-surface: …; --bbs-ink: …; }
.bbs-root[data-theme='night'] { … }
```

而面板容器是 `.bbs-root` 的**兄弟**，CSS 变量只沿 DOM 树向下继承，**兄弟之间不共享** → 容器及其子节点里所有 `var(--bbs-*)` 全部失效（取不到值 → 属性被丢弃或回退成 `inherit`）。再叠加 `:host { all: initial }` 把继承链切断，面板就成了「没有背景、字号/颜色随宿主漂移」的一坨文字。

### 根因二：容器压根没有布局样式

我在仓库和构建产物里搜过 `#bme-panel-host`、`bme-panel-host`：**只有 JS 里的一处 `id` 赋值，没有任何 CSS 规则**。于是：

- 它是一个普通 `div`，`position: static` → 顺着文档流排在 Vue 应用节点之后；
- `#bbs-app-host` 是 `display: contents`，所以它实际上直接参与 `body` 的布局 → 在酒馆页面里出现在**最下方**，被 `#chat` 之类的固定高度区域挤到看不见的地方；
- 没有 `z-index` → 即使出现在视口里也会被 ST 的聊天区、顶栏盖住；
- 没有背景/边框 → 面板里的 `.bme-*` 样式（`createPanel` 内联 `<style>`）虽然生效，但 `.bme-root{color:inherit}`、输入框用 `rgba(0,0,0,.06)` 这类半透明底色在 ST 的深色主题下几乎看不见；
- `hidden` 属性本来是「默认关闭」的开关，但容器是 `display:block` 的普通 div，一旦有别的规则（或将来写成 `display:flex`）覆盖，`hidden` 就会失效 —— 也就是「开关点了看不出来」。

## 三、v1.4.1 的修法

1. **新增 `src/styles/memory-editor.css`**（由 `src/index.ts` 引入，随 `dist/index.css` 一起注入 shadow root），把容器做成右侧抽屉：
   - `position: fixed`（四个方向展开，不用 `inset` 简写，兼容老 WebView）、`height: 100dvh`；
   - `z-index: 10050`（高于柏宝书自己的窗口 10000 与 `bbs-modal-mask-top` 10002）；
   - `display: flex; flex-direction: column` + 内容区 `overflow-y: auto; overscroll-behavior: contain`；
   - 主题化配色（`--bbs-surface / --bbs-ink / --bbs-line / --bbs-accent`…），**每条都带兜底值**，令牌拿不到时也不会透明；
   - 显式写 `#bme-panel-host[hidden] { display: none !important; }`，让「关闭」一定生效；
   - 窄屏（≤640px）整屏抽屉，和主窗口的移动端形态一致；
   - 面板页签条 `.bme-bar` 吸顶，长列表滚动时不丢导航。
2. **容器补上主题作用域**（`src/index.ts`）：`editorHost.className = 'bbs-root'`、`setAttribute('data-theme', ui.theme)`，并用 `watch(() => ui.theme, …)` 跟随设置页/题首的主题切换 —— 兄弟节点就自己带一份作用域，这是最短且不侵入 Vue 应用的解法。
3. **给面板搭一层骨架**（`src/features/memory-editor/host.ts` 的 `ensureChrome()`）：
   - 顶部条：标题「剧情剪辑台」+ 一句说明 + 「刷新」「关闭」两个按钮；
   - 内容区 `div.bme-host-body`，面板本体挂在这里（不再直接挂容器）；
   - `toggleMemoryEditorPanel(force?)` 改为可选参数（关闭按钮与 `Esc` 传 `false`），打开时自动重绘一次，并只绑定一次 `Esc` 监听；
   - `createMemoryEditor()` 新增 `renderPanel()`（`src/features/memory-editor/index.ts` 暴露面板句柄的 `render`），供顶栏「刷新」与开合时强制重绘 —— 之前面板只在创建时渲染一次，外部数据变化（其它页签改了摘要/台账）后打开看到的可能是旧内容。
4. **顺带**：引擎的 `st-baibai-book:changed` 事件现在同时触发 `editor.refresh()`（广播镜像）与 `editor.renderPanel()`（重绘面板）。

## 四、验证

- `npx vue-tsc --noEmit`：0 报错；
- `npm test`：vitest 302 项 + timeRel 810 / vector-depth 12 / memory-regression 53 断言全绿；
- `npm run build`：`dist/index.js` / `dist/index.css` 重建（新样式已进入 `dist/index.css`，可用 `grep -c bme-panel-host dist/index.css` 自检）；
- `npm run check:local`：无白鸟远端产物，手写补摘等本地功能仍在；
- 手工核对（浏览器）：把 `#bme-panel-host` 从隐藏切到显示，应看到右侧滑入的整高抽屉，浅色/深色主题下背景与文字都清晰，`Esc` 与「关闭」都能收起，窄屏下占满整屏。

## 五、如果你还想改风格

- 宽度：`src/styles/memory-editor.css` 里 `#bme-panel-host { width: min(460px, 100vw) }`；
- 位置：把 `top/right/bottom: 0` 换成 `left: 0` + `border-right` 就是左侧抽屉；
- 全屏：`width: 100vw` 并去掉 `border-left`；想要「像主窗口那样的居中弹窗」，改用 `position: fixed; inset: 0; margin: auto; height: 82vh` 即可（主窗口 `.bbs-window` 的写法可参考 `src/styles/base.css`）。
