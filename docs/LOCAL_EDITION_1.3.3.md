# 百宝月夜书 1.3.3 · 本地改版使用说明

这是基于仓库提交 `9e42ccd68c0cc0ea7166d5b2f31553005ab61fe6` 制作的本地修改包，配套手机为1.6.2。已推送到你的GitHub（ansdojaods/ST-BaiBai-Book-Tsukiyo），不是上游官方发布。

## 一、没有AI也能手动补摘现有楼层

路径：**百宝月夜书 → 摘要 → 未摘要楼层 → 对应 #楼层的「手写」**。

1. 展开原文确认楼层；编号与插件现有摘要列表一致。
2. 填写摘要正文，时间可选。
3. 点击「保存手写摘要」。不调用生成API，不自动压缩总结，也不立即调用向量服务。
4. 保存后从待摘要列表移除，进入正常摘要树；小手机实时记忆读取也能使用它。
5. 修改已经保存的内容，使用摘要原有的「编辑」入口。

限制和保护：
- 只接受现有、未被有效摘要覆盖的AI消息；不能为不存在的楼层造摘要，不写到用户楼或系统提示楼。
- 总开关/自动摘要关闭或API不可用，不影响手写入口；AI摘要/批量补摘正在进行时暂不可写，避免抢写。
- 编辑期间切聊天、改正文、切swipe、删消息或该楼已被其他任务补摘，会拒绝旧草稿提交，要求重新选择。
- 摘要文本不自动推断物品、人物、计划、变量等结构化变化，`delta`为空；需要时在相应页面手动维护。
- 时间字段仅标注摘要的时间范围，不伪造结构化时间状态。留空时优先读取本楼已有的时间标签。
- 不改原消息正文、不立即隐藏聊天楼层；后续是否隐藏仍由原有窗口机制处理。暂时保留原文是为了避免误隐藏。
- 叶子沿用原有延迟保存链路（约1.5秒），保存后不要立刻关闭整个页面。替换旧swipe的陈旧叶子之前会尽可能建立恢复点。

## 二、小手机可选读取柏宝书记忆

需要同一个酒馆页面同时启用新版主扩展和新版手机。**不需要白鸟数据或任何新增服务器插件。**生成新消息仍需要你原来配置的LLM渠道；“无需后端插件”不等于“手机生成无需AI”。

两边的读取开关均须允许：

- **百宝月夜书 → 联动 → 小手机联动 → 允许小手机读取柏宝书记忆**。
- **小手机 → 设置 → 柏宝书联动 → 使用柏宝书记忆生成（实时读取）**。

手机「记忆」页还增加了实时读取状态、「切换记忆读取」和「查看当前参考」。查看参考不调用AI。新字段默认允许读取，以保持旧版联动习惯；旧版手机已经关闭`brief`开关的会继续关闭。

### 怎么读、覆盖哪些功能

采用**生成时实时读取**，而不是反复把整本书复制成手机记忆。每次生成刷新简报，使用有限长度的历史摘要、锚点、人物资料、计划、物品和生活细节作为可选参考。

| 功能 | 记忆使用方式 |
|---|---|
| 私聊、主动来信 | 按人物权限读取；允许主线阅读的人物可参考摘要与锚点；不在场且未授权者不取全局摘要 |
| 群聊 | 保守地只加入有限的本人资料/时间，不附整份全局私密摘要和锚点 |
| 朋友圈、多人动态、评论 | 限本人基础资料/时间，不把全局私密摘要当成可公开内容 |
| 玩家日记、备忘、生活清单、日历活动 | 整理视角可参考记忆，要求区分已发生事实和计划 |
| 角色日记 | 传递各自人物上下文中的记忆参考；多人日记不再共用整份近期正文 |
| 规划（包括经过统一生成入口的规划扩展） | 可参考剧情简报，不自动认为未来计划已执行 |
| 交流记忆整理、记忆生成、进度核对 | 记忆仅作背景参考；仍保留原有消息ID、楼层和逐字引文校验，简报不能冒充原文证据 |

对于多人生成，模型仍须遵守每人知情范围。这里是输入裁剪与提示词约束，不是对模型输出的绝对隐私保证。

### 关闭以后

- 停止读取新的柏宝书简报。
- 标记为`bb`的既有导入记忆从本次生成的输入副本中过滤，**不删除手机存档**。
- 不会抹除过去已经生成的消息、日记，或自动识别并撤回已被整理进普通手机记忆/会话摘要中的衍生内容；这些需要用户自行编辑。
- 生成期间改变读取开关，会拒绝该次旧结果提交，要求重新生成。
- 「手机交流回写柏宝书」独立控制。只想手机读取、不要反向回写，可关闭回写；读取关闭但回写开启也可以。

「导入柏宝书记忆」仍可手动使用，但导入的是静态副本，不会持续跟随更新。新导入默认只有玩家知情，不再凭文本提及角色姓名自动授权；旧版本已经导入的知情人设置不会被擅自覆盖，建议自行核对。

## 三、删除白鸟远程后端

你截图的HTTP404表示该部署未提供白鸟后端接口（可能未安装/未启用/路由未暴露）。它依赖酒馆服务器安装服务端插件，无法仅靠浏览器扩展补出来。

本包已经删除：
- 白鸟适配与远程同步实现；
- 启动、进入联动页时的白鸟健康探测；
- 远程自动备份、远程快照列表/恢复/删除、回收站镜像拉取；
- 对应开关、命名空间、404状态和安装提示。

仍保留：恢复点、回收站、JSON导入导出、诊断、锚点、手机联动。旧`backend`设置键名仅为保留恢复点数量/回收站上限，升级时远程字段被丢弃。没有删除你的旧聊天、记忆或服务器上已有的备份。

“本地恢复”指使用现有聊天metadata，由当前酒馆正常存档；不是承诺只存在浏览器硬盘。JSON文件导出才会下载到你的设备。原有可选向量功能是另一套功能，本次未改造；没有对应服务时请继续保持向量功能关闭。

## 四、安装与更新

### 主扩展

完整源码包中已含编译后的`dist/`和`manifest.json`，无需在酒馆服务器跑npm或安装服务端插件。

- 如果你能更新自己的GitHub仓库：上传包内`ST-BaiBai-Book-Tsukiyo/`目录中的文件（不要把外层目录当作仓库根），删除已废弃的`src/backend/bainiao.ts`、`src/backend/sync.ts`和旧手机产物；提交后在酒馆更新扩展并刷新页面。
- 如果已有合法的前端扩展文件替换方式：替换扩展目录文件后刷新。**本助手没有推送你的GitHub，也没有修改别人服务器上的部署。**
- 如果该酒馆连前端扩展更新/安装也禁止，需要部署者允许；此包不能绕过服务器权限。
- 更新前先导出聊天与记忆，勿直接在唯一存档上试新版。

### 小手机

将配套的`月夜来信小手机_酒馆助手导入版_v1.6.2_柏宝书联动.json`导入酒馆助手脚本库。保留原独立脚本ID，允许按现有导入机制覆盖旧版。

**旧独立手机与卡内手机不要同时启用。**如果旧手机嵌在角色卡里，请停用旧脚本后再启用独立版；本次没有改写你的整张角色卡。手机存档命名空间没有更改。
