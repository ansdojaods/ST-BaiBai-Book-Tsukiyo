# 融合功能（安全修复版1.3.4）

当前使用说明以 [SAFETY_EDITION_1.3.4.md](SAFETY_EDITION_1.3.4.md) 为准。

1. 锚点日记：仍支持提取、手工添加、排除和编辑，保留原数据键。
2. 恢复点、回收站、导入导出：使用现有聊天存档，不需要额外服务器插件。
3. 白鸟远程后端：本版已移除，包括探测、自动同步及远端管理入口。旧版安装服务端插件的说明不再适用于本版。
4. 手机联动：支持可关闭的实时读取与独立回写；详见 [PHONE_BRIDGE.md](PHONE_BRIDGE.md)。
5. 摘要页：增加现有未摘要AI楼的手写补摘，不需要API。AI补摘与原有压缩功能仍保留。
6. 摘要缺口默认放行的策略保持不变；临时不能使用AI时，可以关闭自动摘要并手写处理缺口。

沿用源码路径`src/backend/restore.ts`、`trash.ts`仅代表本地恢复逻辑，并不意味着存在白鸟远程服务。
