## 1.4.3 本版修了什么（优化与修复）

- **修复：编辑渠道时的测试会提前改动已保存渠道**：编辑弹窗里测试的是草稿，但之前会把草稿的地址、测试用语、测试结果直接写回已保存渠道，点「取消」也无法撤销。现在草稿测试只改草稿，结果随「完成」保存，「取消」全部作废。列表里的测试不变。
- **新增 CI**：`.github/workflows/verify.yml` 在 push / PR 时跑 `npm run verify`，并检查提交的 `dist/` 与源码重建结果一致。
- **依赖只保留 npm**：删除与 `package-lock.json` 并存的 `pnpm-lock.yaml`。
- **清理死代码与残留**（远程镜像时代的回收站订阅、无引用的包装函数、过时的宏说明等），完整清单与保留理由见 [`CHANGELOG.md`](CHANGELOG.md) 与 [`docs/优化说明_1.4.3.md`](docs/优化说明_1.4.3.md)。

## 1.4.2 本版修了什么（接线修复 + 去重收口）

- **剪辑台召回接进生成流程**：以前宿主从不调用 `recall()`、也从不清空注入槽 —— 剪辑台的召回从未自动生效，手动点一次还会一直挂着。现在生成拦截器放行前调一次召回，剪辑台在「生成结束」时记完账就清空（一次生成一次注入）。
- **「汇入小手机记录」按钮修好**：`notesProvider` 之前没人传，点下去永远提示「没有可汇入的手机记录」。现在接到柏宝书【小手机】外部记录（`source === 'tsukiyo-phone'`）。
- **自动摘要归属二选一**（设置 → 摘要设置 →「自动摘要归属」）：柏宝书摘要森林（默认）/ 剧情剪辑台。选剪辑台后引擎不再自动补摘（`engine.ts` 闸门），避免同一段剧情两次模型调用 + 两个互相矛盾的缺口数字。
- **手机会看总开关了**：`capability()` 增加 `enabled`/`mode`；剪辑台整体关闭时小手机（v2.9.5+）不再让位，继续自己管楼层记忆，堵住「两边都不管」的空档。
- **面板不再空转**：`st-baibai-book:changed` 到达时，面板收起就不重建 DOM，同一轮多次事件合并成一次；魔杖菜单条目显示「剧情剪辑台 · N」待确认角标，自动草稿生成后会 toast 提示。
- **新增 `memoryEditor.open()/close()/toggle()`**：小手机工作台可一键打开剪辑台抽屉；「恋爱心迹」可单独选择是否参与外部记录注入（`phoneBridge.injectHeart`）。
- **清理**：删掉无人引用的 `describeEditor`、修掉 `mountMemoryEditorPanel` 里恒为假的补挂条件、更正挂错位置的注释。
- 验证：`vue-tsc` 0 报错；vitest 302 项 + timeRel 810 / vector-depth 12 / memory 53 断言全绿；剪辑台模块测试 55 → **65 项**（新增 10 项：能力开关 / 一次性注入 / 归属让位 / 草稿提示 / 旧宿主兼容 + 5 项跨仓库契约夹具）；`vite build` + `check:local` 通过。

## 1.4.1 本版修了什么

- **修复「剧情剪辑台在酒馆里显示不对」**（本次的重点，详见 [docs/剪辑台显示修复_1.4.1.md](docs/剪辑台显示修复_1.4.1.md)）：
  - 根因一：面板容器 `#bme-panel-host` 与 Vue 应用根节点（`.bbs-root`）是 **shadow root 里的兄弟节点**，主题令牌 `--bbs-*` 定义在 `.bbs-root` 上 → 容器里 `var(--bbs-*)` 全部取不到值，面板背景透明、字号与颜色错乱。

- **README 清理**：删掉误粘贴进文件的 `</content>` / `</invoke>` 等片段，把手机相关的历史章节合并成一条指向独立仓库的说明。

## 与「月夜来信 · 小手机」的关系（谁是谁）

| 项目 | 形态 | 负责什么 |
| --- | --- | --- |
| **百宝月夜书**（本仓库，`dist/index.js`） | 酒馆**前端扩展** | 楼层摘要森林、向量召回、物品/人物/场景台账、锚点日记、**剧情剪辑台**（1.4.0 起内置） |
| **剧情剪辑台**（本仓库 `src/features/memory-editor/`） | 百宝月夜书里的一个模块，不是独立扩展 | 三层摘要树 / 剧情状态账本 / 记忆缺口与补课 / 可解释召回 / 待确认草稿与撤回 / 脱敏诊断；对外挂 `window.STBaiBaiBook.memoryEditor`（apiVersion 1） |
| **月夜来信 · 小手机**（独立仓库） | 酒馆**助手脚本**（单文件） | 拟真社交与生活手机：私聊/群聊、朋友圈、日记心迹、主动来信、记忆工作台、内置灵魂链接、世界书工坊 |

三者的联动方式（详见 [docs/PHONE_BRIDGE.md](docs/PHONE_BRIDGE.md) 与 [PUBLIC_API.md](PUBLIC_API.md)）：

1. **小手机 ↔ 百宝月夜书**：手机只读 `window.STBaiBaiBook.phone`（`getBrief` 拿剧情简报、借用副 API 渠道），写回走 `pushNotes` → 柏宝书的【小手机】外部记录；柏宝书侧改动时向 `window` 派发 `st-baibai-book:phone-update` 事件。
2. **小手机 ↔ 剧情剪辑台**：手机侧的「记忆工作台」探测 `window.STBaiBaiBook.memoryEditor.capability() / mirror()`；检测到剪辑台**且它开着总开关**时，手机的楼层摘要与楼层记忆注入**让行**（避免两边各写一份摘要、缺口口径打架），可一键关掉回到手机自管；剪辑台关闭时手机继续自己管。手机还能订阅 `st-baibai-book:memory-editor` 事件即时刷新镜像，并用 `open()` 反向打开剪辑台。
3. **剧情剪辑台 ↔ 百宝月夜书**：同一个插件内部，剪辑台的状态随聊天落盘（`chatMetadata.bbs_editor_state`），生成走副 API「摘要」渠道（无渠道回退主 API `generateRaw`），注入用独立槽 `baibai_book_editor`（深度 4，切聊天即清空），入口在**魔杖菜单 →「剧情剪辑台」**。

```bash
npm ci
npm run verify        # 类型检查 → 测试 → 构建 → 无白鸟产物检查
npm run watch         # 边改边构建
```

主扩展更新需包含 `dist/` 和 `manifest.json`；构建产物哈希与测试记录见 `verification/`。

# 柏宝书 · SillyTavern 记忆引擎

> 让你的角色真正「记得住」。柏宝书是一个为 SillyTavern 打造的长期记忆扩展——它会一边陪你聊，一边默默把剧情整理成摘要、盘点物品、记住登场人物、梳理来龙去脉，再在恰当的时候把这些记忆悄悄递给 AI。既省 token，又让长篇对话前后连贯、不失忆、不崩人设。

聊得越久，AI 越容易忘事：早期的约定被抛在脑后，物品凭空消失又出现，角色性格漂移，时间线也乱成一团。柏宝书就是为了解决这些烦恼而生的——它把「记忆」这件事从你手里接管过去，全程自动，几乎无需操心。

---

## 它能做什么

### 📖 自动摘要，永不失忆
- **边聊边记**：每当 AI 回复后，柏宝书会自动把这一楼的剧情整理成一段结构化摘要，并在合适的时候把太旧的原文楼层隐藏起来、改用摘要发送。上下文窗口再也不会被灌满，长对话也能一直聊下去。
- **多层总结**：摘要攒多了会被压缩成「总结」，总结再多还能二次压缩成更上层的概览——就像给剧情建了一套目录，几百楼的故事也能一眼看清脉络。
- **手动随心调**：想自己动手也没问题。任意楼层单独补摘、勾选多条手动合并、一键把落下的楼层批量补齐，全都支持；每条摘要都能直接编辑、删除。
- **详细 / 精简两档**：一键切换摘要的详尽程度——要信息全就选详细，想省 token 就选精简。

### 🕰️ 时间线不再错乱
柏宝书会为每段剧情打上「故事内时间」锚点，让 AI 清楚地知道「现在是什么时候、过了多久」。再也不会出现「昨天的事被当成三年前」或者时间莫名倒流的尴尬。

### 🎒 物品、人物、场景，样样有账本
除了剧情摘要，柏宝书还会自动维护几本「台账」：
- **物品**：谁获得了什么、消耗了什么、东西放在哪儿、随身还是寄存，清清楚楚，还带变动日志，绝不重复结算。
- **角色（NPC）**：登场人物的身份、外貌、性格、当前穿着与状态，谁是核心主演、谁只是路人，自动分级管理——重要角色重点跟踪，龙套不占篇幅。
- **生活小档案**：记录主角与主要角色明确说过或正文揭示的偏好、习惯和近况，每条标明所属人物，不因一次行为推断习惯。相关时才参考，不跨人物合并；旧记录默认仍属主角，可在角色页纠正。
- **内心好感与外在态度**:摘要 AI 分别估计角色对你的内在倾向与外在对待方式,各用五档文字表达,另有"未知"和一句说明。默认保持,不按回合加减分;只有充分新依据才调整,嘴硬、客套或一时情绪不等于感情变化。角色页可查看、手动校正,楼层面板可追溯修改,带数据换对话也会保留。不想跟角色卡自带好感系统并行的话,可在设置 → 注入设置里关掉名册内的好感注入(记录与角色页展示不受影响)。
- **场景**：去过的地点按「由大到小」的层级组织成一棵地图树，复用命名、避免重复，剧情走到哪、人在哪一目了然。
- **计划与悬念**：角色立下的约定、埋下的伏笔、未解的谜题，都会被单独记进「悬念簿」，了结了就核销，避免 AI 把办完的事又拿出来说一遍。

### 🔍 向量记忆：需要时才「想起来」
开启向量记忆后，柏宝书会把历史剧情建成可检索的记忆库。每当续写新剧情时，它会智能判断「这一段可能需要回忆起哪些往事」，多角度检索、精排打分，再把最相关的几段旧记忆悄悄递给 AI 参考。哪怕是三百楼前的一个细节，也能在关键时刻被重新「想起来」。

### 🚚 换对话不丢记忆
- **带数据创建新对话**：一键把当前剧情的最近正文、历史摘要、物品与计划状态打包，开一个全新对话无缝接着聊——旧记忆随行，还能被向量召回。
- **从旧版 Horae 迁移**：用过旧插件 Horae 的老用户，可以把旧的摘要、物品、计划一键搬进柏宝书，不动原数据、平滑过渡。
- **导入旧总结**：以前手写在世界书等位置的剧情总结可以直接粘贴进来，并指定它覆盖到哪一楼；柏宝书从此处接管后续剧情，不再重复总结旧楼。

### 🎨 好看又好用的界面
- 精心设计的多主题界面，自动跟随 SillyTavern 的配色。
- 多种入口任你挑：屏幕悬浮球（可拖动、可换图标）、顶栏按钮、输入框上方按钮，还有每条楼层下方的小面板。
- 楼层面板里可查看该楼摘要与数据变动，还能一键把某楼标记为「番外」——被标记的楼层会被记忆系统彻底忽略，适合小剧场、番外篇，取消即恢复。
- 手机、平板、电脑都适配，操作顺手。

### ⚙️ 想调多细都行
- **独立副 API**：摘要、总结可以指派专门的模型渠道去跑，不占用、也不干扰你的主对话；不想额外配置，直接跟随主 API 也行。
- **自定义提示词**：摘要、总结、破限、时间标签等每一套提示词都能自己改，还提供可点击插入的宏。
- **排除名单**：可以按角色、按世界书整本或按条目名把不需要记忆的内容排除掉，既省 token 又不干扰。
- **内容清洗**：自动剔除思维链、状态栏等格式块，还能自定义要清洗的标签，让摘要只保留真正的剧情。
- **失败重试、超时控制、召回参数**……进阶旋钮一应俱全，也都有合理的默认值，新手无需理会。

## 安装

在 SillyTavern 的「扩展 → 安装扩展」里填入本仓库地址即可：

```
https://github.com/baibai-git/ST-BaiBai-Book
```

安装后进入柏宝书的「设置」页，打开总开关「柏宝书 · 记忆引擎」，按需配置摘要与向量记忆，就能开始使用了。设置会随 SillyTavern 保存在服务器，跨设备、跨局域网自动同步。

## 小贴士

- 摘要、总结默认可以直接「跟随主 API」，零配置就能用；想用更省钱或更擅长整理的模型，再去配副渠道即可。
- 向量记忆是可选项：不开也能正常摘要，开了则能召回更久远的记忆，代价是每回合多一点点延迟。
- 所有记忆数据都跟着聊天走，删聊天即删记忆，隐私可控。
